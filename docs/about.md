# About Resume Studio

Resume Studio is a free, open-source desktop workspace for building CVs and cover letters. It is designed for people who want to keep their career notes and generated documents on their own computer.

## Privacy { #privacy }

Resume Studio has no user account or cloud database. Your notes, imported documents, and generated CVs stay in local files. If you choose an AI action, the relevant CV text and optional job description are passed to the provider CLI you installed and authenticated. The provider processes that request under its own terms and privacy policy; check those terms before use.
