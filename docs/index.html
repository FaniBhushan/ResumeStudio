GETTING STARTED

Install on your computer

Choose the installer for your operating system. Resume Studio runs locally; your documents stay on your computer.

WINDOWS

Run the installer

Download the Windows setup file and follow its prompts. Windows may show SmartScreen because the installer is not signed. Continue only when the download came from this project's Releases page.

macOS

Move it to Applications

Choose Apple silicon or Intel, open the DMG, and drag Resume Studio into Applications. This free release is ad hoc signed but not notarized; macOS may therefore ask you to approve it.

LINUX

Make the AppImage executable

In a terminal, go to the download folder and run chmod +x ResumeStudio-*.AppImage, then launch it with ./ResumeStudio-*.AppImage. Some distributions require FUSE 2 compatibility libraries.

MACOS SECURITY NOTICE

macOS warning: know which message you see

Resume Studio’s free macOS build is not notarized by Apple. Only continue if you downloaded it from this project’s GitHub Releases.

“Apple cannot check it for malicious software”

  1. Try opening Resume Studio once.
  2. Open System Settings → Privacy & Security.
  3. Under Security, select Open Anyway, then confirm the prompt.

“The app is damaged and moved to the Bin”

Stop here; do not use Open Anyway or commands that disable macOS checks. Apple says this can mean the app is corrupted or altered, or that macOS blocked it as malware. This release is not notarized, so we cannot use Apple’s notarization to establish its trust. The latest ARM installer’s code signature verifies, but that alone does not prove the download is safe or explain this alert.

Screenshots and warning guidance: Apple Support — Open apps safely on your Mac.

OPTIONAL AI FEATURES

Install a provider CLI

Install Node.js and npm, then choose a provider. Open its command once to sign in, then restart Resume Studio from a terminal where that command is available on your PATH.

OpenAI Codex

npm install -g @openai/codex@latest

Then run codex and follow the sign-in prompts.

Google Gemini CLI

Then run gemini and choose an authentication option.
