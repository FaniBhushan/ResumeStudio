# Role: Lead Developer - Digital Fueling & Container Apps
**Company:** MBition GmbH  
**Dates:** 01/2023 - 02/2024 (Part of MBition tenure)  
**Location:** Berlin, Germany  

## Project Description
- Built and delivered customer-facing containerized connected car applications for Mercedes-Benz, including the "Fuel & Pay" (Digital Fueling) in-vehicle payment system.
- Designed and maintained secure integration interfaces between onboard vehicle container platforms and public cloud backend microservices.

## Responsibilities & Achievements
- Served as Lead Frontend Developer and Developer Representative, spearheading the design and delivery of the "Fuel & Pay" application UI and integration logic.
- Engineered cloud backend integrations and APIs for key payment features using Golang, Java, and Spring Boot.
- Interfaced directly with stakeholders, product managers, and UX design teams to translate business requirements into concrete architectural designs and technical roadmaps.
- Led the technical implementation of containerized in-car connected applications, ensuring high reliability and compliance with vehicle security standards.

## Technologies
