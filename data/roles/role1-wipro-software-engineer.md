# Role: Software Engineer - Robotic Vacuum Firmware
**Company:** Wipro Technologies  
**Dates:** 08/2010 - 10/2012  
**Location:** Bangalore, India (Vorwerk Germany Client Integration)  

## Project Description
- Developed ARM Linux-based embedded firmware for an autonomous robotic vacuum cleaner (Vorwerk, Germany), delivering core spatial navigation and cleaning features.
- Integrated multiple hardware systems, including LIDAR laser sensors, cliff sensors, dual side brushes, and 5 ultrasonic sensors.
- Supported SLAM (Simultaneous Localization and Mapping) navigation algorithms to optimize pathfinding and coverage efficiency.
- Contributed within an 9-member cross-functional engineering team (6 junior developers, 2 senior developers, 1 tech lead).

## Responsibilities & Achievements
- Engineered drive motion control and autonomous cleaning path algorithms using C++ on ARM Linux.
- Deployed to the client site in Germany to conduct hands-on product demonstrations and integrate feedback.
- Designed hardware-in-the-loop (HIL) test suites, proactively catching and resolving edge-case bugs during pre-production.
- Debugged low-level kernel and application-level issues using GDB, JTAG debuggers, and hardware logic analyzers.

## Technologies
- C++, ARM Linux, SLAM, SVN, JTAG, GDB, HIL Testing, Sensor Fusion (Laser, Cliff, Ultrasonic, Bumper)
