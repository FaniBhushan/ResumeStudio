# Role: Senior Software Engineer - Navigation Engine (Harman Client)
**Company:** Wipro Technologies  
**Dates:** 04/2012 - 09/2013  
**Location:** Bangalore, India  

## Project Description
- Developed, maintained, and optimized software components for a high-performance C++ navigation engine deployed in Harman in-vehicle infotainment (IVI) systems.
- Supported core navigation subsystems including path routing, localization, route guidance, Point-of-Interest (POI) search, and map presentation controller.
- Collaborated within an 8-member engineering team to deliver software updates under strict automotive guidelines.

## Responsibilities & Achievements
- Enhanced the routing subsystem by optimizing pathfinding algorithms based on the A* graph search method.
- Ramped up routing domain knowledge within the team by analyzing legacy codebase documentation, creating comprehensive knowledge-base resources, and conducting technical training sessions.
- Authored extensive unit tests and performed regression analysis to ensure high reliability of navigation features.
- Diagnosed and fixed complex system bugs using Visual Studio, memory analysis tools, and Harman proprietary route/map validation utilities.

## Technologies
- C++, QNX RTOS, A* Search, Visual Studio, Harman Map Validation Tools, Unit Testing (GTest/similar)
